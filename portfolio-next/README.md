# portfolio-next

Scaffold inicial do portfolio migrado para Next.js + TypeScript + Tailwind.

Para executar:

```bash
cd portfolio-next
npm install
npm run dev
```

Copiar imagens do projeto Vue para o Next (executar a partir da raiz do repositório):

```bash
cd portfolio-next
npm run copy-assets
```

Isso copia `src/assets/img/*` → `portfolio-next/public/img/`.
